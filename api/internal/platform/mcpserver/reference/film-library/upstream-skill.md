# Film planning reference

Reference only; this document is not an installed skill or an executable workflow.

1. Read the brief and existing preferences. Ask only for missing creative direction, source permissions and spending approval.
2. Choose a visual language from `film-styles`; retrieve its complete source by exact ID.
3. Read the directing guide for story, staging, rhythm and camera. Translate the chosen visual language into a subject-specific treatment and production contract.
4. Author complete Svelte/Three.js scenes using the deployed machinal runtime. Do not install or execute external setup, rendering or audio pipelines.
5. Preserve approved assets and existing captions. Compile and review the resolved edit before any authorized paid rendering.

For personal styles, read the `my-styles` reference and save a complete project-local style note only when requested.
