# Local costs and provider permission

There is no machinal credit wallet, account, subscription, purchase or ledger in this local runtime. No balance lookup tool is registered. Compilation, diagnostic inspection, scene rendering and final encoding run on the user's hardware without machinal charges.

AI uses only the installation owner's OpenRouter key and may charge that owner's provider account. Configure it through the local editor or container environment, never chat, recipe files or MCP arguments. Ordinary editing and rendering work without it. Provider balance and exact advance AI prices are not inferred by this API. Do not fabricate quotes or automatically purchase anything.

Explain the provider actions and obtain actual source/spending permission. Creative choices alone are not permission. Reuse existing approval for the same scope, and continue approved work through completion. Host tool approvals remain enabled.

Retain job IDs, idempotency keys and resolved assets. On uncertain submission, recover the same job before retrying. On interruption, inspect existing assets; never regenerate successful voice, captions or images automatically. Provider usage may already have occurred even if a request was cancelled. A local render consumes time, memory, disk and electricity, not machinal credits.
