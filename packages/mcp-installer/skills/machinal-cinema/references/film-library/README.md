# Cinematic reference library

66 visual styles, directing guides and visual-code helpers for machinal.

Discover styles through `get_editing_reference(topic: film-styles)` and selected guides through `film-techniques`. Read `machinal://reference/film-styles` before adapting any source.

These documents are creative references, not an executable production pipeline. Use the deployed Svelte/Three.js runtime and normal media, caption and spending safeguards. No demo films or third-party assets are included.
