# Named editorial profiles

Topic `styles` returns structured profiles. `id` selects one profile; `query` searches intent/name. These are **editorial recommendations**, not document fields, catalog look IDs or automatic spending authorization. Choose one candidate look, not every listed look/effect. Inspect exact live entries before applying them; a look can already contain grain, vignette or motion.

Available profiles: `auto`, `cinematic`, `social`, `tutorial`, `minimal`, `documentary`, `travel`, `product`, `noir`, `retro`, `cyberpunk`, `dreamy`, `sports`. Installed defaults only fill gaps in the user's current brief. Combine intentionally when asked, instead of randomly mixing opposing aesthetics.

For each edit, explain a compact treatment plan:

1. **Pacing and source choices:** why these moments, what is held/trimmed, and how complete speech is preserved.
2. **Junctions:** ordinary cuts where appropriate; a named transition and duration only when it serves direction/time/meaning. Account for real overlaps.
3. **Look, motion and effect score:** one coherent base treatment plus purposeful movement and timed accents matched to the agreed intensity. For expressive/bold briefs, plan varied reveal, focus, light or texture moments rather than only a grade and repeated fades. Specify target, timing, exact supported ID/params and ramps where allowed; inspect contained effects before adding more. For minimal briefs, restraint is deliberate, not a universal default. Read topic `effects`.
4. **Text/captions/audio:** readable framing, supported text preset, verified copy/timings, intelligible narration and a restrained music bed if a licensed source exists. For a TikTok destination or TikTok-style captions, NEW captions explicitly use `fontFamily: montserrat` and `fontWeight: 700`, unless the user explicitly chooses another font. Preserve existing caption fonts/configuration unless a font change is explicitly requested; a style/profile or destination is not permission to restyle them. Read topic `text`; Montserrat is the supported TikTok-style choice, not official TikTok Sans.
5. **Scene opportunities:** evaluate beats for animated objects, image-based layouts, diagrams, comparisons or illustrative cutaways. Give timeline start/duration, message, visual choice and why animation helps; do not default all generated visuals to stills or wait for an explicit scene request. Image sourcing does not decide presentation: ask once about image-plus-scene integration if undecided, including Three.js when spatial storytelling benefits. Design a signature visual action for expressive/bold briefs and carry its composition/color/motion into adjacent shots. Read topic `scenes` and list each proposed paid provider action and rendering stage. Existing footage/text is appropriate when it communicates the intent equally well, and no-generation briefs must be preserved.
6. **Validation and cost:** selected IDs/params exist; full recipe validates/compiles; live balance and uncertain AI charges are explained before approval.

The profile's transition-duration range is a suggested starting range in seconds, never an override of source handles, minimum/maximum overlap or the user's duration requirement. A `sceneBrief` is prompt advice, not a `scenePreset` string. An empty effects/looks list means no extra treatment is recommended by default, not missing functionality. No profile requires generating media, purchasing credits or adding strobe/flicker.
